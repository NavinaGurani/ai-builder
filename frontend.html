Creating a basic calculator app can be done using HTML, CSS, and JavaScript. Below is a simple example of how to create a basic calculator that can perform addition, subtraction, multiplication, and division. ### Step 1: HTML Structure Create an `index.html` file with the following markup: ```html Basic Calculator
``` ### Step 2: CSS Styles Create a `styles.css` file for basic styling: ```css body { display: flex; justify-content: center; align-items: center; height: 100vh; background-color: #f0f0f0; font-family: Arial, sans-serif; } .calculator { border: 1px solid #ccc; border-radius: 10px; padding: 20px; background-color: white; box-shadow: 0 0 10px rgba(0, 0, 0, 0.1); } #display { width: 100%; height: 40px; margin-bottom: 10px; text-align: right; font-size: 18px; border: 1px solid #ccc; border-radius: 5px; padding: 5px; } .buttons { display: grid; grid-template-columns: repeat(4, 1fr); gap: 10px; } button { padding: 20px; font-size: 18px; border: none; border-radius: 5px; background-color: #007bff; color: white; cursor: pointer; } button:hover { background-color: #0056b3; } ``` ### Step 3: JavaScript Logic Create a `script.js` file to handle the calculator logic: ```javascript function appendToDisplay(value) { document.getElementById("display").value += value; } function clearDisplay() { document.getElementById("display").value = ''; } function calculateResult() { const display = document.getElementById("display"); try { display.value = eval(display.value); } catch (error) { display.value = 'Error'; } } ``` ### How to Run the App 1. Create a new directory and inside that directory, create three files: `index.html`, `styles.css`, and `script.js`. 2. Copy and paste the code provided into the respective files. 3. Open `index.html` in your web browser to see your basic calculator in action. ### Features of the Calculator - The calculator supports basic arithmetic operations: addition, subtraction, multiplication, and division. - You can clear the display by clicking the "C" button. - It uses the `eval` function to evaluate the expression; make sure to use it carefully in a real-world application. Feel free to enhance the styling or functionality as per your requirements!
